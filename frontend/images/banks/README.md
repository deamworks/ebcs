# โลโก้ธนาคาร (ใบนำฝากชำระเงิน)

วางไฟล์รูปโลโก้ธนาคารในโฟลเดอร์นี้ ใช้ชื่อไฟล์ตรงตามด้านล่าง (พิมพ์เล็ก, .png) แล้วจะขึ้นในใบนำฝากอัตโนมัติ
แนะนำ: PNG พื้นหลังโปร่งใส ขนาดประมาณ 32x32px ขึ้นไป

| ธนาคาร | ชื่อไฟล์ |
|---|---|
| กสิกรไทย | `kbank.png` |
| ทีเอ็มบีธนชาติ | `ttb.png` |
| ซีไอเอ็มบีไทย | `cimb.png` |
| ไอซีบีซี(ไทย) | `icbc.png` |
| เกียรตินาคิน | `kkp.png` |
| ไทยพาณิชย์ | `scb.png` |
| ออมสิน | `gsb.png` |
| ยูโอบี | `uob.png` |
| ซิตี้แบงก์ เอ็น.เอ. | `citi.png` |
| กรุงไทย | `ktb.png` |
| กรุงเทพ | `bbl.png` |
| มิซูโฮ | `mizuho.png` |
| กรุงศรีอยุธยา | `bay.png` |
| ทิสโก้ | `tisco.png` |

ถ้ายังไม่มีไฟล์ ระบบจะซ่อนรูปที่โหลดไม่ได้ให้อัตโนมัติ เหลือแค่ชื่อธนาคารเฉยๆ ไม่ error
